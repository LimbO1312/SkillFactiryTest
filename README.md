# Проект тестов авторизации

## Описание проекта

Тесты написаны на Python с использованием библиотек `pytest` и `selenium`. Сценарии тестируют корректность обработки логина и пароля, включая различные типы учетных данных (email, телефон, логин). Посмотреть тест-кейсы для этого проекта можно здесь: https://docs.google.com/spreadsheets/d/1-8KrLShCXCOAnAO0NhbO9is9bwRItLJQ/edit?usp=sharing&ouid=106347734300639116377&rtpof=true&sd=true

## Структура проекта

- `TestLogin`: Класс, содержащий тесты для проверки функциональности авторизации.
- `Login_Page_Web.py`: Базовый класс страницы авторизации.
- `readConfig.py`: Утилита для чтения конфигурационных данных.
- Конфигурационные файлы: Содержат тестовые данные, такие как URL-адреса, логины и пароли.

## Предварительные требования

Перед запуском тестов убедитесь, что у вас установлено следующее:

- Python 3.8 или выше
- Необходимые библиотеки:
  - `pytest`
  - `selenium`
- Веб-драйвер (например, ChromeDriver) для браузера, используемого в тестах.
